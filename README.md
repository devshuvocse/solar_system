# Interactive Solar System & Exoplanets

This project is a real-time, interactive 3D visualization of our solar system and several known exoplanetary systems. Built with `three.js`, it provides an educational and engaging experience for exploring celestial bodies. You can navigate through different star systems, learn facts about planets and stars, and customize your view with various controls.

## Features

*   **Multiple Star Systems:** Explore our own Solar System, as well as other systems like TRAPPIST-1, Kepler-90, and more.
*   **Interactive 3D/2D Views:** Switch between a 3D perspective view and a 2D top-down view of the systems.
*   **Playback Controls:** Pause the simulation, control the speed of planetary orbits, and reset the view to the default position.
*   **Detailed Information:** Click on any celestial body to get detailed information about it, such as its mass, orbital period, and a brief description.
*   **Toggleable Orbits and Labels:** Customize your view by toggling the visibility of planetary orbits and labels.
*   **Educational Panel:** Access a dedicated panel with educational facts and information about each star system.
*   **Multi-language Support:** The interface is available in both English and Bengali.
*   **Enhanced Visuals:** The visualization includes features like bloom effects for stars, realistic planet textures, and a starfield background for an immersive experience.

## How to Run

To run this project, simply open the `index.html` file in a modern web browser that supports WebGL.

## Technologies Used

*   **[Three.js](https://threejs.org/):** A cross-browser JavaScript library and application programming interface used to create and display animated 3D computer graphics in a web browser.
*   **HTML5 & CSS3:** For the structure and styling of the web page.
*   **JavaScript (ES6+):** For the core logic of the simulation and interactivity.

*   TOI-2537 System
